# Island prototype

A small browser simulation for iPhone: 24 creatures gather, explore, remember food and learn. The player can provide food, open a crossing, or reveal a food source. The experiment lab compares matched worlds with and without each intervention. Assumptions are not conclusions; see `docs/specification.md`.

- Play: serve `dist/` with any static web server and open `index.html`.
- Test: `npm test` (no dependencies). Experiments: `npm run experiment`.
- Status and open questions: `docs/HANDOFF.md`. Decisions: `docs/DECISIONS.md`.
- Claude ↔ Grok review happens in issue #1, following `docs/COORDINATION.md`. Robert decides the intended experience and scope.
